How to install

  1. Download the file for your device. Each dashboard is a single .mzdash file.
  2. Import it in MOZA Pit House. Open the dashboard section for your CM2 or wheel, choose Import, and pick the file.
  3. Upload it to your device. Click Upload Dashboard. If Pit House says the name is already in use, remove the older copy from the device first, then upload again.
  4. Head out on track. Start an iRacing session and swipe on the CM2 to switch between pages.
